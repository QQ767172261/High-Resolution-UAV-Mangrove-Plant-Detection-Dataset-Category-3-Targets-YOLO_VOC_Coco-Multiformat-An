## 应用价值![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/4e9c7d9bbd12421f97abfb6c8692b789.png)


1. **红树林生态调查自动化**：利用无人机航拍影像自动识别、计数红树林开花植株与胚轴幼苗，替代人工野外调查，大幅减少滩涂外业调查工作量。
2. **红树林种群动态监测**：统计开花植株数量、胚轴幼苗分布，监测红树林繁殖更新情况，评估红树林群落生长状态。
3. **滨海湿地生态保护**：为红树林修复成效评估、保护区资源普查、湿地生态演替分析提供AI基础数据。
4. **遥感小目标检测算法研究**：高分辨率航拍样本，适用于大分辨率图像下植被小目标检测模型训练，可用于生态遥感、植被识别相关科研实验。
5. **国土湿地项目落地**：支撑自然资源、生态环境部门红树林本底调查、生态修复项目验收。![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/5a4b8f6a01fd4f34b345a19b9f8a251f.png)

## 摘要

**高分辨率无人机红树林植株检测数据集｜3类目标，YOLO/VOC/COCO多格式标注**
正文摘要：
本红树林植株检测数据集由无人机高分辨率航拍采集，共426张2160×3840影像，提供YOLO、VOC、COCO三种标注，包含开花植株、红树林胚轴等3类目标。数据集划分训练/验证/测试子集，可训练AI模型自动识别红树林繁殖个体，用于滨海红树林资源普查、种群更新监测、湿地生态修复评估。
